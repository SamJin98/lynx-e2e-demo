# Upstream attribution

The three hooks in this directory and `src/assets/{1,3,4}.png` originate from
[lynx-family/lynx-examples, examples/swiper](https://github.com/lynx-family/lynx-examples/tree/main/examples/swiper),
licensed under Apache-2.0. The upstream license is retained in `LICENSE` here.

`useOffset.ts` was modified to cancel a running snap animation before selecting
a page. The other hooks have formatting changes. Product photography is unchanged.
The surrounding furniture page, desktop input adapter, and tests are demo additions.
